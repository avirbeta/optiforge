# OptiForge 1.1.0

Оптимизатор FPS для **Minecraft 1.16.5** (Fabric). Автоматически определяет железо ПК и установленные моды и подстраивает настройки игры под них — повышает FPS и убирает лаги (частицы, дроп энтити, сканирование чанков) на слабых компьютерах.

## Что нового в 1.1.0

- Починен FPS-метр: раньше `FpsMeter.tick()` нигде не вызывался, поэтому авто-понижение настроек при низком FPS не срабатывало.
- Динамическое понижение тира больше не зависит от флага «показывать предупреждения».
- GPU определяется через OpenGL (`GL_RENDERER`), а не считается всегда дискретным.
- ОЗУ определяется честно через ОС, а не как лимит heap JVM.
- Исправлено условие сканирования частиц: при выключенной оптимизации оно работало каждый тик.
- Конфиг валидируется: битые и огромные значения не ломают игру.
- Добавлены CI-сборка и MIT-лицензия.

## Возможности

- Автоопределение железа (CPU, ОЗУ, GPU).
- Определение установленных модов (sodium, lithium, phosphor, OptiForge-совместимые и свои).
- Автонастройка: дальность прорисовки (viewDistance), частицы, графика, FOV.
- Оптимизация энтити/дропа/частиц/блоков (EntityOptimizer, ItemOptimizer, BlockEntityOptimizer, ParticleOptimizer).
- HUD с FPS и текущим профилем оптимизации.
- Экран настроек (клавиша **F6**).

## Сборка

Требуется: JDK 21, Gradle 9.9+, Fabric Loom 1.11.8, yarn `1.21.10+build.3:v2`, fabric-api `0.138.4+1.21.10`.

```bash
gradle build --no-daemon
```

Готовый мод: `build/libs/optiforge-2.0.0-1.21.10.jar`.

Сборка также запускается в GitHub Actions при каждом push — готовый jar лежит в артефактах workflow.

## Установка

1. Установи **Fabric Loader** для 1.16.5 и **Fabric API** `0.42.0+1.16`.
2. Положи `optiforge-1.1.0.jar` в папку `mods/`.
3. Запусти игру, нажми **F6** для настроек.
